## Projects

### Note-Taking App

A web application where users can sign in with Google and create, edit, and delete their personal notes. It features a two-column interface for browsing and editing notes, with each user's notes kept separate from other accounts.

Building this app taught me how to handle requests with Express, store notes in MongoDB, and make sure users can only access their own notes.

**Technologies used:** JavaScript · Node.js · Express · MongoDB · EJS · Google OAuth

[View source code on GitHub](https://github.com/N1kos07/NoteTakingAPP)
